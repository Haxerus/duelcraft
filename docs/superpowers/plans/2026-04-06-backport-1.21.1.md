# Backport Duelcraft to Minecraft 1.21.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backport Duelcraft from MC 1.21.11 / NeoForge 21.11.42 to MC 1.21.1 / NeoForge 21.1.77 for LDLib2 compatibility and broader mod ecosystem support.

**Architecture:** The backport touches build config, 4 payload files (Identifier rename), networking registration (merge client handlers into common registration), DuelScreen (input method signature changes), and DuelcraftClient (simplify). All core game logic, message parsing, response building, and duel session code is pure Java and unchanged.

**Tech Stack:** NeoForge 21.1.77, MC 1.21.1, Java 21, Parchment 2024.11.17

---

## Summary of API Differences (1.21.11 → 1.21.1)

| Area | 1.21.11 (current) | 1.21.1 (target) |
|------|-------------------|-----------------|
| Resource IDs | `net.minecraft.resources.Identifier` | `net.minecraft.resources.ResourceLocation` |
| Screen input | `mouseClicked(MouseButtonEvent, boolean)` | `mouseClicked(double, double, int)` |
| Screen input | `keyPressed(KeyEvent)` | `keyPressed(int, int, int)` |
| Client→Server packets | `ClientPacketDistributor.sendToServer()` | `PacketDistributor.sendToServer()` |
| Client payload registration | Separate `RegisterClientPayloadHandlersEvent` | Handlers passed to `registrar.playToClient()` directly |
| Screen background | `renderBackground(GuiGraphics, int, int, float)` | Same (verify) |
| Tooltip | `g.setTooltipForNextFrame(...)` | Possibly `setTooltipForNextRenderPass(...)` — verify at compile |

### Task 3: Merge Client Payload Handlers into DuelNetworking

In MC 1.21.11, client payload handlers were registered separately via `RegisterClientPayloadHandlersEvent` in `DuelcraftClient`. In NeoForge 1.21.1, that event doesn't exist — handlers must be passed directly to `registrar.playToClient()`.

**Files:**
- Modify: `src/main/java/com/haxerus/duelcraft/server/DuelNetworking.java`
- Modify: `src/main/java/com/haxerus/duelcraft/DuelcraftClient.java`

- [ ] **Step 1: Update DuelNetworking.java to include client handlers**

Replace the entire file content:

```java
package com.haxerus.duelcraft.server;

import com.haxerus.duelcraft.client.ClientPayloadHandler;
import net.neoforged.neoforge.network.event.RegisterPayloadHandlersEvent;
import net.neoforged.neoforge.network.registration.PayloadRegistrar;

public class DuelNetworking {
    public static void onRegisterPayloads(RegisterPayloadHandlersEvent event) {
        PayloadRegistrar registrar = event.registrar("1");

        // Server → Client (handlers run on client only)
        registrar.playToClient(DuelStartPayload.TYPE, DuelStartPayload.STREAM_CODEC,
                ClientPayloadHandler::handleStart);
        registrar.playToClient(DuelMessagePayload.TYPE, DuelMessagePayload.STREAM_CODEC,
                ClientPayloadHandler::handleMessage);
        registrar.playToClient(DuelEndPayload.TYPE, DuelEndPayload.STREAM_CODEC,
                ClientPayloadHandler::handleEnd);

        // Client → Server
        registrar.playToServer(DuelResponsePayload.TYPE, DuelResponsePayload.STREAM_CODEC,
                ServerPayloadHandler::handleResponse);
    }
}
```

Note: `playToClient` handlers are only invoked on the physical client. NeoForge ensures these handlers never fire on dedicated servers.

- [ ] **Step 2: Remove client payload registration from DuelcraftClient.java**

Replace the entire file content:

```java
package com.haxerus.duelcraft;

import net.minecraft.client.Minecraft;
import net.neoforged.api.distmarker.Dist;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.fml.ModContainer;
import net.neoforged.fml.common.Mod;
import net.neoforged.fml.event.lifecycle.FMLClientSetupEvent;
import net.neoforged.neoforge.client.gui.ConfigurationScreen;
import net.neoforged.neoforge.client.gui.IConfigScreenFactory;

@Mod(value = Duelcraft.MODID, dist = Dist.CLIENT)
public class DuelcraftClient {
    public DuelcraftClient(IEventBus modBus, ModContainer container) {
        container.registerExtensionPoint(IConfigScreenFactory.class, ConfigurationScreen::new);
        modBus.addListener(DuelcraftClient::onClientSetup);
    }

    private static void onClientSetup(FMLClientSetupEvent event) {
        Duelcraft.LOGGER.info("HELLO FROM CLIENT SETUP");
        Duelcraft.LOGGER.info("MINECRAFT NAME >> {}", Minecraft.getInstance().getUser().getName());
    }
}
```

Changes from original:
- Removed `@EventBusSubscriber` annotation (using manual registration via constructor instead)
- Removed `RegisterClientPayloadHandlersEvent` handler (moved to `DuelNetworking`)
- Constructor now takes `IEventBus modBus` and registers listener manually
- Removed unused imports (`SubscribeEvent`, `EventBusSubscriber`, payload types)
