These HTML sketches establish layout and hierarchy. They do not prove LDLib2 sizing, Minecraft font rendering or gameplay behavior. Rich filters are represented, not replaced by a reduced production feature set. The logical canvas is 1280×720; the size switch previews uniform scaling, not responsive reflow. The same content makes comparison easier. Gallery is the approved direction. Real-client fixture proof is implemented; human hierarchy, legibility and sharpness acceptance and production migration remain pending.
